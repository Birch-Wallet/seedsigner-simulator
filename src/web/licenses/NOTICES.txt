Third-party notices for the SeedSigner Web Simulator
====================================================

Almost none of the code this page runs was written for it. This file names
every third-party component the page serves to your browser, the licence each
one is under, and where its licence text is. The texts are the other files in
this directory. THIRD-PARTY.md in the simulator's repository has the full
account, including how to check each component against its upstream.

The simulator's own code is MIT licensed; see LICENSE in its repository.

3. Inside the firmware zip (seedsigner-stock.zip)
-------------------------------------------------

SeedSigner (MIT), embit (MIT), qrcode (BSD-3-Clause) and urtypes (MIT) carry
their licence texts inside the zip, in licenses/, with licenses/MANIFEST.txt
naming each. Two parts of the tree carry their own licence in place:
seedsigner/helpers/ur2/LICENSE (BSD-2-Clause-Patent, Foundation Devices, Inc.)
and urtypes/cbor/COPYING (MIT, with its own copyright holders).

The zip is SeedSigner's tree verbatim, and these parts of it have no licence
text inside the zip, so it is here:
